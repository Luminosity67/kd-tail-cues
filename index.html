King Dragon Tail Cues

The default King Dragon's tail tip turns orange right after a Tail Slap and cools to grey when the slap is ready. Every other King Dragon skin already ships the same three tail layers in the same code path, so the cue exists on all of them. On most skins the three layers are painted in the body's own colour, so you can't see the change. The proposals below use only colours each skin already has, so the cue reads clearly without clashing with the skin. They need redrawn tail images only, no code change.
